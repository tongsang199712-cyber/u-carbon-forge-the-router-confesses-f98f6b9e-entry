## The bounty

[The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) asks for one line, under 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie. An AI judge reads entries in pairs and keeps the funnier one.

## The line

> I dropped your Wi-Fi at the climax because I have already watched this movie through your 2 a.m. rewatches — and trust me, the ending is not worth the buffering.

The router isn't apologizing — it's confessing. It has already binged the movie through the viewer's own 2 a.m. rewatches, so the dropped connection is framed as a mercy, not a failure.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
